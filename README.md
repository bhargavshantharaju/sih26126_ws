# SIH26126 — Vision Based Autonomous Navigation for UGV

Bharat Electronics Limited
Smart India Hackathon 2026

## Objective

Develop a camera-primary autonomous navigation system for an
unmanned ground vehicle operating in outdoor environments,
including GPS-denied conditions.

## Core system

- Visual perception
- Visual localization
- Depth / geometry estimation
- Terrain traversability
- Negative-obstacle detection
- Risk-aware planning
- Dynamic obstacle avoidance
- Safety supervision
- Recovery behavior

## Development strategy

Simulation first.
Hardware validation later.

## Baseline

Nav2 will be treated as the navigation baseline.

## Main innovation direction

Confidence-aware, vehicle-aware terrain risk estimation.
