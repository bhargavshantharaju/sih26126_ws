### Physical Justification

**max_pose_speed_mps = 2.5 m/s**
- Robot model SDF max velocity: Configured for differential drive
- Safety supervisor max_linear_speed: 0.30 m/s (line 155 in safety_supervisor.py)
- EKF max expected velocity: ~0.5 m/s for normal autonomous navigation
- Threshold rationale: 2.5 m/s provides 5x headroom above normal operation
- This accounts for:
  * SLAM corrections during loop closures (±0.3-0.5m typical)
  * Sensor discretization and timing jitter
  * EKF covariance updates causing brief position jumps
- Status: APPROPRIATE for physics and sensor characteristics

**pose_jump_margin_m = 0.10 m**
- Purpose: Tolerate measurement noise when elapsed ≤ 0
- Rationale: LiDAR resolution (0.05m), scan matching precision (~0.05-0.10m)
- At 0.1s intervals: allows 0.10m noise floor
- At 0.025s intervals: allows 0.10m noise floor (not velocity-based)
- Status: APPROPRIATE for sensor noise characteristics

**pose_discontinuity_safe_stop_count = 3**
- Purpose: Distinguish genuine instability from isolated SLAM corrections
- Rationale: 
  * 1 event: Possible loop closure or scan match adjustment (ACCEPT)
  * 2 events: Possible transient (WARN but CONTINUE)
  * 3 events: Systematic failure (SAFE_STOP)
- Timing: At 10 Hz pose rate, 3 events = 0.3s window
- Status: APPROPRIATE for distinguishing noise from failure

**pose_startup_grace_sec = 15.0 s**
- Purpose: Suppress frame-change discontinuities during SLAM initialization
- Rationale: SLAM may switch between visual_odom and map frames during startup
- Frame changes are NOT implausible motion, just frame transitions
- Status: APPROPRIATE for startup stability

### Validation Logic (pose_jump_exceeded function)

```python
def pose_jump_exceeded(distance_m, elapsed_s, max_speed_mps=2.0, margin_m=0.10):
    if elapsed_s <= 0.0:
        # Only flag if movement exceeds margin (not any micro-movement)
        return distance_m > max(0.0, margin_m)
    return distance_m > max(0.0, max_speed_mps) * elapsed_s + max(0.0, margin_m)
```

**Zero/Negative Elapsed Guard**: CORRECT
- Before fix: `distance > 1e-4` (effectively any movement flagged)
- After fix: `distance > margin_m` (only flag large jumps)
- Verified by regression tests (test_zero_elapsed_small_move_is_accepted PASSED)

**Normal Motion Check**: CORRECT
- Formula: distance > (speed × time + margin)
- Example: 2.5 m/s, 0.1s → threshold = 2.5*0.1 + 0.10 = 0.35m
- Observed in Test #1: 0.46m in 0.1s → 0.46 > 0.35 → CORRECTLY FLAGGED
- Observed in Test #2: 0.349m in 0.025s → 0.349 > 0.1625 → CORRECTLY FLAGGED (isolated, no SAFE_STOP)
